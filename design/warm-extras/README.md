# Warm extras: design reference

Build the app screens to MATCH these files (layout, spacing, colours, wording).
- TodayWarm.png/.html: Today with scene, note for this payday, mini chart
- Scenes.png/.html: the 5 scene stages (0, 25, 50, 75 percent, debt-free)
- Reads.png/.html: Short reads list (10 reads, yellow tick = read)
- Read.png/.html: one open read

Rules: no red, yellow only for done/paid/read, no em dashes, no exclamation marks,
works offline, scene stage comes from percent of total debt paid, note and reads
chosen from the user's real state (first payday, buffer low, debt gone...).
The .html files are static mockups: copy the SVG and CSS, wire the data yourself.
