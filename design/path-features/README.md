# Path features: design reference

Build to MATCH these (layout, wording, colours). Numbers are Nadia's test plan.
- Chapters.png/.html: Path view "Chapters" (replaces List). One card per debt, payday squares (yellow = paid), "You are here", flag line when a debt is gone, house at the end.
- WholePlan.png/.html: opened from one card at the top of Path. Total to debts (balance + interest), plan vs minimums-only interest bars, next 30 days split, totals by year.
- ComingLater.png/.html: inside "I got extra money". Now / Later switch, optional type chip, ONE typed field (amount), payday defaults to the next one, effect shown before saving.

Rules: 4 tabs only, at most 1 typed field per feature, no red, yellow only for paid/done, no exclamation marks.
Expected Nadia values: chapters Store card 5 paydays (6 Nov to 1 Jan 2027), Medical 3 (15 Jan to 12 Feb), Visa 11 (26 Feb to 16 Jul 2027). Whole plan $3,528 = $3,250 + $278 interest; minimums only $1,445; next 30 days $446 = $146 debts + $280 buffer + $20 yearly; 2026 $842, 2027 $3,176. Coming later: $800 on Fri 9 Apr 2027 -> debt-free Fri 21 May 2027, 4 paydays sooner, $36 less interest.
